Novas instruções para a tabela Nexus Centralizado

Quando:
	PROBLEMA = Queda de ligação ou PROBLEMA = Queda Ligação Durante Atendimento e API = sem funcionalidade
Então: 
	TIPO = Improdutivo
	CATEGORIA = Problema Interno
	CATEGORIA_DETALHE = Queda de Ligação

Quando:
	PROBLEMA = Atendente não concluiu registro ou PROBLEMA = vazio:
Então: 
	TIPO = Indefinido
	CATEGORIA = Problema Interno
	CATEGORIA_DETALHE = Registro não concluído



Os operadores não devem prestar atendimento aos técnicos que não utilizaram a funcionalidade exigida pelo fluxo antes do atendimento.
O operador deve informar e finalizar o atendimento até 3 min
Coluna para identificar se o técnico acionou indevidamente para esse caso: CATEGORIA = Indevido Uso MagicTool.
Criar uma nova coluna para identificar isso.
